# Cutting edge

A Windows video editor for manually synchronized screen and camera recordings, reusable assets and local subtitles. The Electron main process owns files and external processes. The sandboxed renderer uses ES modules, native media elements and a restricted preload bridge. The project file contains editing decisions. Source recordings stay intact.

## Project and time

Project JSON uses `{schema:1,id,name,width,height,fps,format,quality,assets,clips}`. Formats are lowercase mp4, mov, mkv, webm. Quality is draft, balanced or high. Assets are a dictionary keyed by ID. Each asset is `{id,name,path,kind,category,duration,width,height,hasAudio,group?,variant?,previewPath?,thumbnail?}`. Kind is video, audio or image (animated GIFs use video); category is media, global, audiofx, visualfx or sticker. Duration is in seconds. Images have an initial duration of five seconds. Static images may extend. Only visualfx and sticker moving picture assets loop. Audio effects end at their source duration.

Every clip has `{id,name,kind,start,in,duration,track,box,crop,volume,muted}`. Kinds are media (assetId), compound (children), text (text,style) or caption (cues,style). All times use seconds. Start is on the containing timeline; in is the offset into the source (or into a compound's child timeline or caption cue timeline). Tracks start at zero from back to front. Box and crop are `{x,y,w,h}`, normalized to the parent canvas and original source respectively, top-left origin. Default box and crop are the full frame. After cropping, media fills its box. New visual media should get an aspect-preserving centered box. A compound is an independent full-project-size canvas including transparent areas, rendered into its box. Children retain offsets and internal track order. Overlapping clips on one track are stacked in array order. Volume is a linear factor, muted is boolean, including on compounds.

Caption cues are `{start,end,text}` in local seconds. Text/caption boxes constrain rendering, center aligned horizontally/vertically. Style is `{font,size,color,stroke,strokeWidth,background,bold,italic}`, sizes in pixels at project resolution, colors #rrggbb; background can be 'transparent'. The UI wraps caption cues into short lines with literal newlines, using one font size per caption clip. Source and export honor those lines.

## Modules

- `app/engine.cjs` exports async `probeAsset(path)` returning kind,duration,width,height,hasAudio, `renderProject(project,destination,{onProgress}={})` (0..1), `detectSilence(project,{db,minDuration})` returning silent `[{start,end}]`, and `transcribe(project,{language,model,onProgress}={})` returning timed cues. Render jobs use private temporary directories, local FFmpeg and ListenActive; deliver files atomically. The main process feeds either a whole project or a clone with a single selected clip moved to time zero. `app/engine.cjs` additionally exports `getBinaries()` returning Promise<{ffmpeg,ffprobe}> for proxies/thumbnails, including bundled tools. Resolve bundled tools from process.resourcesPath/tools or repo tools. Local media paths may contain spaces, apostrophes and Polish text.
- `ui/model.mjs` exports `makeClip(project,asset,start,track)`, `makeCompound(project,ids)` (update project in place, return new clip), `cutSilence(project,id,ranges)` (ranges relative to clip's visible start; edit in place and ripple following clips), `splitClip(project,id,time)`, `endTime(project)`, `fullBox()`. Document any extra exports.
- `ui/editor.mjs` exports `mountEditor({stage,timeline,transport,getProject,getSelection,select,commit,onTime,flags,translate,assetUrl,dropAsset,inspect})` returning `{refresh,playPause,seek,getTime,setZoom,getZoom,destroy}`. Stage, timeline and transport are container HTMLElements; UI shell sizes them. Selection is an array of top-level clip IDs. select(ids), commit(fn) for undoable mutation (fn receives current project). onTime(seconds), flags() => {timelineSnap,sceneSnap,language}; translate(pl,en) returns one string. assetUrl(absolutePath) returns a playable local URL; dropAsset(assetId,time,track) adds from current library to the project. inspect(clipId) opens inspector. Library drag data MIME text/x-cutting-asset carries the asset ID. Editor owns scoped CSS for its three containers in ui/editor.css. Support selecting multiple clips, dragging, trimming, playhead, synchronized playback, visual manipulation and scene/timeline snapping. Shell handles hotkeys including Space, S (split), M (timeline snap), G (scene snap), Delete, undo.
- `app/assistant.cjs` exports async `askAssistant({project,selection,message,history,language,libraryDir,onEvent})` => `{reply,actions}`. Model sees editing instructions and can propose validated live edits. Actions consumed by shell: `{type:'update',id,patch}` (name,start,in,duration,track,box,crop,volume,muted,text,style); `{type:'remove',id}`; `{type:'addText',text,start,duration,track,box?,style?}`; `{type:'insertAsset',path,category,start,track,group?,variant?}`; `{type:'split',id,time}`; `{type:'compound',ids}`. Generated and downloaded media paths go in the appropriate library folder. The renderer applies one undoable batch. libraryDir contains subdirectories global, audiofx, visualfx and sticker. A sticker group uses a subfolder named after the group; variants are filenames. Stock sticker pack lives in assets/library/sticker/<group>/<variant>.gif and is copied on initial import. Assistant receives only metadata and user messages through the signed-in local Codex CLI, which returns structured commands.
- Windows distribution uses Electron packager or electron-builder directory output at dist/win-unpacked, app exe 'Cutting edge.exe', and Inno Setup for per-user installation. Output installer is dist/Cutting-edge-Setup-x64.exe. GitHub repo szymongazinski/Cutting-edge, tag v1.0.0 for first release. Inno stores first-run directories in HKCU\Software\Cutting edge strings ProjectDir and OutputDir. Installer can be run repeatedly for upgrades. `app/updater.cjs` exports `checkUpdate(currentVersion)` => {available,version,url}, `installUpdate(currentVersion)` starts verified installer; caller quits only on success. See release script for hashes.
